## المستوى 5: الأوامر والاستجابات

```
Computer → Device (الأوامر)
│
├─── AutoCSA Commands
│    ├─ R → Reset
│    ├─ N → Manual Mode
│    ├─ A → Automation Mode
│    ├─ T → Top Plate
│    ├─ I → Imprinting
│    ├─ S → Start Automation
│    ├─ O → Stop Automation
│    ├─ H → Hinge Check
│    ├─ M → Moisture Check
│    └─ P → Pressure Check
│
└─── Prototype Commands
     ├─ 0 → Reset
     ├─ M → Moisture Check
     ├─ P → Pressure Check
     └─ Pxx → Set Point (xx=Hex)

Device → Computer (الاستجابات)
│
├─── AutoCSA Responses
│    ├─ E → Idle Mode
│    ├─ O → Idle Automation
│    ├─ I → Imprinting Active
│    ├─ H → Valid Hinge ✓
│    ├─ Z → Invalid Hinge ✗
│    ├─ L → Valid Moisture ✓
│    ├─ X → Invalid Moisture ✗
│    ├─ P → Valid Pressure ✓
│    ├─ Y → Invalid Pressure ✗
│    └─ W → Probes Disconnected
│
├─── Prototype Responses
│    ├─ E → Alive (مستمر)
│    ├─ M → Valid Moisture ✓
│    ├─ N → Invalid Moisture ✗
│    ├─ P → Valid Pressure ✓
│    └─ Q → Invalid Pressure ✗
│
└─── CSA Readings (القراءات)
     └─ 00xx → قيمة رقمية (Hex)
```

## المستوى 10: مسارات التنفيذ

### Path 1: فحص بسيط
```
User Click → Start → SetPoint → Read → Save → Next → Done
  (1s)      (100ms)  (200ms)   (2s)   (200ms) (loop)  (عرض)
```

### Path 2: فحص آلي كامل
```
Start → Connect → Validate → Automate → Scan → Dosage → Report
(1s)     (3s)      (30s)      (1s)      (3min)  (يدوي)   (طباعة)
```

### Path 3: Broadcasting
```
Select Items → Broadcast → Wait → Complete
  (يدوي)        (100ms)    (حسب العدد) (إشعار)
```

## المستوى 13: Troubleshooting Decision Tree

```
المشكلة؟
│
├─ لا يتصل
│   ├─ المنفذ موجود في Device Manager؟
│   │   ├─ نعم → Port In Use؟
│   │   │   ├─ نعم → أغلق التطبيقات الأخرى
│   │   │   └─ لا → جرب Auto Detection
│   │   └─ لا → تحقق من الكابل + Driver
│   │
├─ يتصل لكن لا قراءات
│   ├─ IsReadingOn = true؟
│   │   ├─ نعم → Events مشتركة؟
│   │   │   ├─ نعم → خفّض MinimumReadingtoRegister
│   │   │   └─ لا → Subscribe to Events
│   │   └─ لا → استدعي StartReading()
│   │
├─ قراءات غير مستقرة
│   ├─ زد ReadingStabilityRange
│   ├─ زد ReadingStabilityTimeout
│   └─ استخدم Continuous Mode
│   │
├─ ينقطع باستمرار
│   ├─ زد CsaDisconnectedTimeout
│   ├─ تحقق من الكابل
│   └─ حدّث Driver
│   │
└─ Broadcasting لا يعمل
    ├─ IsBroadcastingOn = true؟
    ├─ الجهاز متصل؟
    └─ FlushBroadcastBuffer()
```
