# 🏥 Vital Expert - محاكي الجهاز الطبي

## 📋 نظرة عامة

هذا المشروع يوفر حلول شاملة لمحاكاة الجهاز الطبي في نظام Vital Expert، مما يتيح للمطورين العمل والاختبار بدون الحاجة للجهاز الفعلي.

## 🎯 المشكلة المحلولة

**المشكلة**: عدم توفر الجهاز الطبي أثناء التطوير مما يعيق عملية البرمجة والاختبار.

**الحل**: محاكي شامل يحاكي جميع وظائف الجهاز الحقيقي مع إمكانيات تحكم متقدمة.

## 🚀 المميزات

### ✅ المحاكاة المدمجة
- تفعيل فوري بدون إعداد معقد
- محاكاة كاملة لجميع وظائف الجهاز
- دعم التحكم بلوحة المفاتيح

### ✅ المحاكي المتقدم
- واجهة تحكم رسومية
- أنواع محاكاة متعددة (عشوائي، ثابت، متزايد، موجي)
- مراقبة القراءات الحية
- سجل مفصل للعمليات

### ✅ سهولة النشر
- ملفات تشغيل سريع للمطور والمستخدم
- إعدادات منفصلة قابلة للتخصيص
- دليل شامل للاستخدام

## 🛠️ التثبيت والإعداد

### للمطور (Development)

1. **تفعيل المحاكاة**:
   ```bash
   # تشغيل الملف التلقائي
   QuickStart_DevMode.bat
   
   # أو يدوياً في App.config
   <add key="UseSimulatedReadings" value="true"/>
   ```

2. **تشغيل التطبيق**:
   - افتح `XtraFormAutoTest`
   - اضغط Start
   - استخدم مفاتيح التحكم أثناء الاختبار

### للمستخدم النهائي (Production)

1. **إعداد الجهاز الحقيقي**:
   ```bash
   # تشغيل الملف التلقائي
   QuickStart_ProductionMode.bat
   ```

2. **في حالة عدم توفر الجهاز**:
   - استخدم وضع المحاكاة مؤقتاً
   - اتبع دليل استكشاف الأخطاء

## 🎮 كيفية الاستخدام

### التحكم الأساسي

| المفتاح | الوظيفة |
|---------|---------|
| `Left Shift` | قراءات عالية (نتيجة إيجابية) |
| `Left Ctrl` | قراءات منخفضة (نتيجة سلبية) |
| `بدون مفاتيح` | قراءات عشوائية تلقائية |

### واجهة التحكم المتقدمة

```csharp
// فتح واجهة التحكم من الكود
var simulatorForm = new DeviceSimulatorControlForm();
simulatorForm.Show();
```

## ⚙️ الإعدادات المهمة

### إعدادات التطوير السريع
```xml
<add key="UseSimulatedReadings" value="true"/>
<add key="ReadingStabilityDelay" value="1"/>        <!-- سرعة عالية -->
<add key="HardwareCheckDelay" value="500"/>         <!-- فحص سريع -->
```

### إعدادات الإنتاج
```xml
<add key="UseSimulatedReadings" value="false"/>
<add key="ReadingStabilityDelay" value="10"/>       <!-- استقرار طبيعي -->
<add key="HardwareCheckDelay" value="3500"/>        <!-- فحص شامل -->
```

## 🚨 استكشاف الأخطاء

### المشكلة: المحاكاة لا تعمل
```
الأسباب المحتملة:
❌ UseSimulatedReadings = false
❌ الملف لم يُحفظ بعد التعديل
❌ التطبيق لم يُعاد تشغيله

الحل:
✅ تأكد من UseSimulatedReadings = true
✅ احفظ الملف وأعد التشغيل
✅ تحقق من ملف Log للأخطاء
```

### المشكلة: القراءات لا تتغير
```
الأسباب المحتملة:
❌ UseStableReadingsOnly = true
❌ عدم الضغط على مفاتيح التحكم
❌ الاختبار متوقف

الحل:
✅ جرب الضغط على Left Shift/Ctrl
✅ تأكد من أن الاختبار يعمل
✅ أعد بدء الاختبار
```

### المشكلة: النظام بطيء
```
الأسباب المحتملة:
❌ ReadingStabilityDelay عالي
❌ HardwareCheckDelay عالي
❌ موارد النظام محدودة

الحل:
✅ قلل قيم التأخير في الإعدادات
✅ تأكد من موارد النظام الكافية
✅ أغلق البرامج غير الضرورية
```

## 📦 النشر للمستخدم النهائي

### الخيار 1: نسخة مع محاكاة (للاختبار)
```bash
1. اضبط UseSimulatedReadings = true
2. اكمبايل المشروع
3. انسخ المجلد كاملاً
4. أرفق QuickStart_DevMode.bat
5. أرفق دليل الاستخدام
```

### الخيار 2: نسخة للإنتاج (جهاز حقيقي)
```bash
1. اضبط UseSimulatedReadings = false  
2. تأكد من إعدادات الجهاز
3. اكمبايل المشروع
4. انسخ مع تعريفات الجهاز
5. أرفق QuickStart_ProductionMode.bat
```

### الخيار 3: نسخة مرنة (تدعم الاثنين)
```bash
1. أرفق كلا ملفي التشغيل السريع
2. أرفق DeviceSimulatorSettings.config
3. أرفق دليل التبديل بين الأوضاع
```
