# تحليل المشروع - الاتصال بالأجهزة الطبية CSA و Auto

## نظرة عامة
المشروع هو نظام Vital Expert لإدارة الفحوصات الطبية باستخدام أجهزة طبية. يتصل النظام بجهازين رئيسيين:
1. **CSA (جهاز القياس التقليدي)**
2. **Auto/Prototype (الجهاز المطوّر الآلي)**

---

## 1. الأجهزة الطبية في المشروع

### 1.1 جهاز CSA (التقليدي)
- **الاسم**: CSA Emd Unit
- **الوظيفة**: جهاز قياس طبي تقليدي يستخدم لقراءة القياسات الحيوية
- **الموقع في الكود**: `BusinessLayer/Vital.Business/Managers/CsaEmdUnitManager.cs`
- **النوع**: `HardwareType.CSA`

### 1.2 جهاز Auto (المطوّر)
- **الاسم**: Auto/Prototype Device
- **الوظيفة**: جهاز محدّث يجمع بين قدرات CSA + إمكانيات آلية متقدمة
- **المدراء المخصصة له**:
  - `AutoCsaEmdUnitManager.cs` - النسخة الأولى
  - `AutoCsaEmdUnitManagerPhase2.cs` - النسخة المحدثة (Phase 2)
- **يدعم**: 
  - **CSA للقراءات**: نفس وظائف جهاز CSA
  - **Prototype للتحكم الآلي**: التحكم في نقاط الاختبار والأتمتة

## 3. طريقة الاتصال (Connection Method)

### 3.1 التقنية المستخدمة
**كلا الجهازين يستخدمان Serial Port Communication (منفذ تسلسلي COM)**

### 3.2 إعدادات الاتصال التفصيلية

#### للوصول: `BusinessLayer/Vital.Business.Shared/Filters/SerialPortConnectionFilter.cs`

```csharp
public class SerialPortConnectionFilter : SerailPortNumberFilter
{
    public SerialPortConnectionFilter(HardwareType hardwareType)
    {
        switch (hardwareType)
        {
            case HardwareType.CSA:
                BaudRate = 1200;      // سرعة النقل
                DataBit = 8;          // بتات البيانات
                Timeout = 1500;       // وقت الانتظار (مللي ثانية)
                Dtr = false;          // Data Terminal Ready
                Rts = true;           // Request To Send
                break;
                
            case HardwareType.Prototype:
                BaudRate = 9600;      // سرعة أعلى للجهاز المطور
                DataBit = 8;
                Timeout = 2000;       // وقت انتظار أطول
                Dtr = false;
                Rts = true;
                break;
        }
    }
}
```

### 3.3 خصائص الاتصال

| الخاصية | CSA | Auto/Prototype | الوصف |
|---------|-----|----------------|-------|
| **BaudRate** | 1200 | 9600 | سرعة نقل البيانات (bps) |
| **DataBit** | 8 | 8 | عدد بتات البيانات |
| **Timeout** | 1500ms | 2000ms | وقت الانتظار الأقصى |
| **Dtr** | false | false | Data Terminal Ready |
| **Rts** | true | true | Request To Send |
| **Parity** | None | None | التحقق من التماثل |
| **StopBits** | 1 | 1 | بتات التوقف |

### 3.4 مساعد الاتصال (Communication Helper)

**الموقع**: `Vital.Hardware/Vital.Hardware/Helpers/HwCommunicationHelper.cs`

هذا الكلاس يدير:
- فتح وإغلاق المنفذ التسلسلي
- قراءة وكتابة البيانات
- استقبال القراءات من الجهاز
- إدارة Buffer للبيانات

```csharp
// مثال على فتح اتصال
public bool Open(int portNumber, int baudRate, int dataBits, Parity parity, StopBits stopBits)
{
    _serialPort.PortName = string.Format("COM{0}", portNumber);
    _serialPort.BaudRate = baudRate;
    _serialPort.DataBits = dataBits;
    _serialPort.Open();
    return true;
}
```

## 5. عملية فتح الاتصال (Connection Flow)

### 5.1 لجهاز CSA التقليدي

```
1. RefreshSettings() ← تحميل الإعدادات من قاعدة البيانات
   ↓
2. RefreshPortNumberSettings() ← قراءة CommunicationsPort
   ↓
3. OpenConnection()
   ↓
4. إنشاء SerialPortConnectionFilter(HardwareType.CSA)
   - BaudRate = 1200
   - DataBit = 8
   - Timeout = 1500
   ↓
5. _csaEmdUnitRepository.OpenConnection(comPort, baudRate, ...)
   ↓
6. HwCommunicationHelper.Open() ← فتح Serial Port
   ↓
7. Connected Event ← إطلاق حدث الاتصال
```

### 5.2 لجهاز Auto المطور

```
1. RefreshSettings()
   ↓
2. RefreshPortNumberSettings()
   - قراءة CommunicationsPort للـ CSA
   - قراءة AutoTestDeviceComPort للـ Prototype
   ↓
3. OpenCSAConnection() ← اتصال CSA
   SerialPortConnectionFilter(HardwareType.CSA)
   - BaudRate = 1200
   ↓
4. OpenPrototypeConnection() ← اتصال Prototype
   SerialPortConnectionFilter(HardwareType.Prototype)
   - BaudRate = 9600
   ↓
5. كلا الاتصالين يعملان بشكل مستقل
```

## 8. أوضاع القراءة (Reading Modes)

### في AutoCsaEmdUnitManager

```csharp
public enum AutoCSAReadingMode
{
    Continuous,      // مستمر - بدون انتظار الاستقرار
    StableReading,   // مستقر - ينتظر استقرار القراءة
    Mixed           // مختلط - يجمع بين الاثنين
}

public void SetReadingMode(AutoCSAReadingMode mode)
{
    switch (mode)
    {
        case AutoCSAReadingMode.Continuous:
            _autoCsaEmdUnitRepository.ReadingStabilityEnabled = false;
            break;
        case AutoCSAReadingMode.Mixed:
        case AutoCSAReadingMode.StableReading:
            _autoCsaEmdUnitRepository.ReadingStabilityEnabled = true;
            break;
    }
    ReadingMode = mode;
}
```

## 10. الملخص التنفيذي

### موقع إعدادات الاتصال
1. **قاعدة البيانات**: جدول Settings
   - `CommunicationsPort` → COM Port لـ CSA
   - `AutoTestDeviceComPort` → COM Port لـ Prototype/Auto

2. **الكود**:
   - `SharedEnums.cs` → تعريفات SettingKeys
   - `SerialPortConnectionFilter.cs` → إعدادات الاتصال
   - Managers → تحميل الإعدادات واستخدامها

### طريقة الاتصال
- **التقنية**: Serial Port (COM Port)
- **CSA**: BaudRate=1200, Timeout=1500ms
- **Auto/Prototype**: BaudRate=9600, Timeout=2000ms
- **مساعد**: `HwCommunicationHelper.cs`

### التفريق بين الجهازين
1. **Enum HardwareType**: CSA vs Prototype
2. **Managers منفصلة**:
   - `CsaEmdUnitManager` → CSA فقط
   - `AutoCsaEmdUnitManager` → CSA + Prototype
   - `AutoCsaEmdUnitManagerPhase2` → نسخة محسّنة
3. **عدد الاتصالات**:
   - CSA: اتصال واحد
   - Auto: اتصالان منفصلان
4. **الإمكانيات**:
   - CSA: قراءات + broadcasting
   - Auto: قراءات + broadcasting + تحكم آلي + فحوصات متقدمة
