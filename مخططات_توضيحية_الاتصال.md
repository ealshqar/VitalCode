# مخططات توضيحية - الاتصال بالأجهزة الطبية

## 1. البنية الهرمية للمشروع

```
Vital Expert System
│
├── CSA Device (التقليدي)
│   │
│   ├── Manager: CsaEmdUnitManager
│   ├── Connection: Serial Port (COM)
│   ├── BaudRate: 1200
│   └── Capabilities:
│       ├── Reading (القراءات)
│       ├── Broadcasting (البث)
│       └── Reset (إعادة تعيين)
│
└── Auto Device (المطور)
    │
    ├── Manager: AutoCsaEmdUnitManager / Phase2
    │
    ├── CSA Component (مكون القراءات)
    │   ├── Connection: Serial Port (COM)
    │   ├── BaudRate: 1200
    │   ├── Setting Key: CommunicationsPort
    │   └── Functions: Reading + Broadcasting
    │
    └── Prototype Component (مكون التحكم)
        ├── Connection: Serial Port (COM)
        ├── BaudRate: 9600
        ├── Setting Key: AutoTestDeviceComPort
        └── Functions:
            ├── Point Selection (تحديد النقاط)
            ├── Automation Control (التحكم الآلي)
            ├── Moisture Check (فحص الرطوبة)
            ├── Pressure Check (فحص الضغط)
            └── Hinge Check (فحص المفصل)
```

## 9. مخطط: Serial Port Communication Details

```
┌────────────────────────────────────────────────┐
│           Serial Port Configuration            │
├────────────────────────────────────────────────┤
│                                                │
│  Property         │  CSA      │  Prototype     │
│  ────────────────────────────────────────────  │
│  Port Name        │  COM1-12  │  COM1-12       │
│  Baud Rate        │  1200     │  9600          │
│  Data Bits        │  8        │  8             │
│  Parity           │  None     │  None          │
│  Stop Bits        │  1        │  1             │
│  Flow Control     │  None     │  None          │
│  DTR Enable       │  False    │  False         │
│  RTS Enable       │  True     │  True          │
│  Read Timeout     │  1500ms   │  2000ms        │
│  Write Timeout    │  Infinite │  Infinite      │
│  Encoding         │  ASCII    │  ASCII         │
│                                                │
└────────────────────────────────────────────────┘

Data Format (تنسيق البيانات):
┌──────────────────────────────────────┐
│ Start Bit │ Data (8 bits) │ Stop Bit│
└──────────────────────────────────────┘

Reading Example (مثال قراءة):
Device → Computer
┌────────────────────────────┐
│ "00FF" → Reading Value: 127│
└────────────────────────────┘

Command Example (مثال أمر):
Computer → Device
┌────────────────────────────┐
│ "P05" → Set Point 5        │
└────────────────────────────┘
```
