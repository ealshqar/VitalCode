# أمثلة برمجية - الاتصال بالأجهزة الطبية

## 1. مثال: الاتصال بجهاز CSA التقليدي

### 1.1 الاتصال البسيط

```csharp
// في: CsaEmdUnitManager.cs

// الحصول على instance من المدير (Singleton)
var csaManager = CsaEmdUnitManager.Instance;

// تحميل الإعدادات من قاعدة البيانات
csaManager.RefreshSettings();

// فتح الاتصال (يستخدم الإعدادات المحملة)
var result = csaManager.OpenConnection();

if (result.IsSucceed)
{
    Console.WriteLine("CSA متصل بنجاح!");
    Console.WriteLine($"COM Port: {csaManager.ComPortNumber}");
}
else
{
    Console.WriteLine("فشل الاتصال بـ CSA");
}
```

### 1.2 الاتصال مع تحديد منفذ يدويًا

```csharp
// إنشاء Filter بإعدادات مخصصة
var connectionFilter = new SerialPortConnectionFilter(HardwareType.CSA)
{
    ComPortNumber = 3,              // COM3
    BaudRate = 1200,                // السرعة
    DataBit = 8,                    // بتات البيانات
    Timeout = 1500,                 // وقت الانتظار
    Dtr = false,
    Rts = true,
    AutoComPortDetection = false     // تعطيل الكشف التلقائي
};

// فتح الاتصال باستخدام Filter
var result = csaManager.OpenConnection(connectionFilter);
```

### 1.3 الاتصال مع الكشف التلقائي

```csharp
// تفعيل الكشف التلقائي
var autoFilter = new SerialPortConnectionFilter(HardwareType.CSA)
{
    ComPortNumber = 0,               // 0 = Auto Detection
    AutoComPortDetection = true,
    Timeout = 1500
};

// الاشتراك في حدث Detecting لمعرفة المنفذ قيد الاختبار
csaManager.Detecting += (sender, portNumber) =>
{
    Console.WriteLine($"جاري اختبار COM{portNumber}...");
};

// الاشتراك في حدث Connected
csaManager.Connected += (sender) =>
{
    Console.WriteLine($"تم الاتصال بنجاح على COM{csaManager.ComPortNumber}");
};

// فتح الاتصال
var result = csaManager.OpenConnection(autoFilter);
```

## 2. مثال: قراءة القيم من CSA

### 2.1 القراءة البسيطة

```csharp
// بدء القراءة
csaManager.StartReading();

// الاشتراك في حدث تغيير القراءة
csaManager.MeterValueChanged += (sender, reading, min, max) =>
{
    Console.WriteLine($"القراءة الحالية: {reading}");
    Console.WriteLine($"الحد الأدنى: {min}");
    Console.WriteLine($"الحد الأقصى: {max}");
    
    // تحديث واجهة المستخدم
    UpdateMeterDisplay(reading, min, max);
};

// الاشتراك في حدث اكتمال القراءة (عندما تستقر)
csaManager.ReadingDone += (sender, reading, min, max, fall, rais) =>
{
    Console.WriteLine($"القراءة المستقرة: {reading}");
    Console.WriteLine($"السقوط: {fall}, الارتفاع: {rais}");
    
    // حفظ القراءة
    SaveReading(reading, min, max);
    
    // إصدار صوت تنبيه
    if (csaManager.BeepDuration > 0)
    {
        Console.Beep(csaManager.BeepFrequency, csaManager.BeepDuration);
    }
};

// الاشتراك في حدث التحرير (عندما يرفع المستخدم الأدوات)
csaManager.Released += (sender) =>
{
    Console.WriteLine("تم رفع الأدوات من الجسم");
    // الانتقال للنقطة التالية
    MoveToNextPoint();
};
```

### 2.2 إيقاف القراءة

```csharp
// إيقاف القراءة
csaManager.StopReading();

// إلغاء الاشتراك في الأحداث
csaManager.MeterValueChanged -= MeterValueChangedHandler;
csaManager.ReadingDone -= ReadingDoneHandler;
csaManager.Released -= ReleasedHandler;
```

## 3. مثال: Broadcasting (البث الطاقي)

### 3.1 بث قائمة عناصر

```csharp
// قائمة العناصر للبث
var itemsToBroadcast = new List<Item>
{
    new Item { Id = 1, Name = "Vitamin C" },
    new Item { Id = 2, Name = "Zinc" },
    new Item { Id = 3, Name = "Magnesium" }
};

// بث العناصر (ليس Imprinting)
var broadcastResult = csaManager.Broadcast(itemsToBroadcast, isImprinting: false, flush: true);

if (broadcastResult.IsSucceed)
{
    Console.WriteLine("تم البث بنجاح");
}
```

### 3.2 Imprinting (الطباعة الطاقية)

```csharp
// العناصر للطباعة الطاقية
var itemsToImprint = new List<Item>
{
    new Item { Id = 10, Name = "Remedy A" },
    new Item { Id = 11, Name = "Remedy B" }
};

// بدء Imprinting
var imprintResult = csaManager.Broadcast(itemsToImprint, isImprinting: true, flush: true);

// التحقق من حالة Imprinting
if (csaManager.IsImprinting)
{
    Console.WriteLine("عملية Imprinting جارية...");
    
    // عرض تقدم العملية
    while (csaManager.IsBroadcasting)
    {
        Console.Write(".");
        Thread.Sleep(500);
    }
    
    Console.WriteLine("\nاكتملت عملية Imprinting");
}
```

### 3.3 اختيار طريقة البث

```csharp
// في الإعدادات، يمكن اختيار طريقة البث
// BroadcastMethodology يُحمل من قاعدة البيانات

switch (csaManager.BroadcastMethodology)
{
    case BroadcastMethodologies.VitalMessage:

        break;
        
    case BroadcastMethodologies.BlankString:
        Console.WriteLine("يتم بث اسم العنصر فقط");
        break;
        
    case BroadcastMethodologies.VitalDegreeOfAffect:
        Console.WriteLine("يتم بث درجة التأثير");
        break;
        
    case BroadcastMethodologies.VitalMessageIngredients:
        Console.WriteLine("يتم بث المكونات");
        break;
}
```

## 5. مثال: أوضاع القراءة المختلفة

### 5.1 وضع القراءة المستمرة (Continuous)

```csharp
// تعيين وضع القراءة المستمرة
autoManager.SetReadingMode(AutoCSAReadingMode.Continuous);

// بدء القراءة
autoManager.StartReading();

// في هذا الوضع، ستحصل على تحديثات مستمرة
autoManager.MeterValueChanged += (sender, reading, min, max) =>
{
    // يتم استدعاء هذا الحدث باستمرار
    Console.WriteLine($"قراءة: {reading}");
};
```

### 5.2 وضع القراءة المستقرة (Stable)

```csharp
// تعيين وضع القراءة المستقرة
autoManager.SetReadingMode(AutoCSAReadingMode.StableReading);

// بدء القراءة
autoManager.StartReading();

// في هذا الوضع، تنتظر استقرار القراءة
autoManager.ReadingStabled += (sender, reading, min, max, fall, rais) =>
{
    // يتم استدعاء هذا عند استقرار القراءة فقط
    Console.WriteLine($"قراءة مستقرة: {reading}");
    
    // يتم إيقاف القراءة تلقائيًا
};
```

### 5.3 الوضع المختلط (Mixed)

```csharp
// تعيين الوضع المختلط
autoManager.SetReadingMode(AutoCSAReadingMode.Mixed);

// بدء القراءة
autoManager.StartReading();

// في هذا الوضع:
// 1. تحصل على تحديثات مستمرة
autoManager.MeterValueChanged += (sender, reading, min, max) =>
{
    Console.WriteLine($"قراءة حية: {reading}");
};

// 2. وتحصل على إشعار عند الاستقرار
autoManager.ReadingStabled += (sender, reading, min, max, fall, rais) =>
{
    Console.WriteLine($"استقرت على: {reading}");
    // لا يتم إيقاف القراءة تلقائيًا في الوضع المختلط
};

// 3. إشعار عند توقف القراءة
autoManager.ReadingStopped += (sender) =>
{
    Console.WriteLine("توقفت القراءة");
};
```

## 8. مثال: معالجة الأخطاء

```csharp
try
{
    var connectionFilter = new SerialPortConnectionFilter(HardwareType.CSA)
    {
        ComPortNumber = 3,
        Timeout = 1500
    };
    
    var result = csaManager.OpenConnection(connectionFilter);
    
    if (!result.IsSucceed)
    {
        Console.WriteLine("فشل الاتصال بـ CSA");

        connectionFilter.AutoComPortDetection = true;

        {
            Console.WriteLine($"✓ تم الاتصال تلقائيًا على COM{csaManager.ComPortNumber}");
        }
    }
}
catch (VitalHardwareException ex)
{
    Console.WriteLine($"خطأ في الجهاز: {ex.Message}");
    Logger.LogError(ex);

catch (Exception ex)
{
    Console.WriteLine($"خطأ غير متوقع: {ex.Message}");

}
```

## 9. مثال: سيناريو كامل للفحص الآلي

```csharp
public class AutoTestScenario
{
    private AutoCsaEmdUnitManagerPhase2 _autoManager;
    private List<TestingPoint> _testingPoints;
    private int _currentPointIndex = 0;
    
    public async Task RunAutoTestAsync()
    {
        // 1. التهيئة
        Console.WriteLine("=== بدء الفحص الآلي ===");
        _autoManager = AutoCsaEmdUnitManagerPhase2.Instance;
        _autoManager.RefreshSettings();
        
        // 2. فتح الاتصال
        Console.WriteLine("1. الاتصال بالأجهزة...");
        var csaResult = _autoManager.OpenCSAConnection();
        
        if (!csaResult.IsSucceed)
        {
            Console.WriteLine("✗ فشل الاتصال بـ CSA");
            return;
        }
        Console.WriteLine("✓ CSA متصل");
        
        // 3. تحميل نقاط الاختبار
        Console.WriteLine("2. تحميل نقاط الاختبار...");
        _testingPoints = LoadTestingPoints();
        Console.WriteLine($"✓ تم تحميل {_testingPoints.Count} نقطة");
        
        // 4. إعداد الجهاز
        Console.WriteLine("3. إعداد الجهاز...");
        
        // تفعيل الوضع الآلي
        _autoManager.ActivateAutomationMode();
        await WaitForCondition(() => _autoManager.CurrentMode == AutoCSAMode.Automation);
        Console.WriteLine("✓ الوضع الآلي مفعّل");
        
        // تفعيل اللوح العلوي
        _autoManager.ActivateTopPlate();
        await WaitForCondition(() => _autoManager.IsTopPlateActive == true);
        Console.WriteLine("✓ اللوح العلوي مفعّل");
        
        // 5. إجراء الفحوصات الأولية
        Console.WriteLine("4. الفحوصات الأولية...");
        await PerformInitialChecks();
        
        // 6. تعيين وضع القراءة
        _autoManager.SetReadingMode(AutoCSAReadingMode.StableReading);
        Console.WriteLine("✓ وضع القراءة: مستقر");
        
        // 7. الاشتراك في الأحداث
        SetupEventHandlers();
        
        // 8. بدء الأتمتة
        Console.WriteLine("5. بدء الأتمتة...");
        _autoManager.StartAutomation();
        await WaitForCondition(() => _autoManager.IsAutomationStarted == true);
        Console.WriteLine("✓ بدأت الأتمتة");
        
        // 9. معالجة النقاط
        Console.WriteLine("6. بدء الفحص...");
        await ProcessAllPoints();
        
        // 10. إنهاء الفحص
        Console.WriteLine("7. إنهاء الفحص...");
        _autoManager.StopAutomation();
        Console.WriteLine("=== اكتمل الفحص الآلي ===");
    }
    
    private async Task PerformInitialChecks()
    {
        // فحص الرطوبة
        _autoManager.PerformMoistureCehck();
        await WaitForCondition(() => _autoManager.HasValidMoisture != null);
        
        if (_autoManager.HasValidMoisture == true)
            Console.WriteLine("  ✓ الرطوبة: مناسبة");
        else
            Console.WriteLine("  ✗ الرطوبة: غير مناسبة");
        
        // فحص الضغط
        _autoManager.PerformPressureCheck();
        await WaitForCondition(() => _autoManager.HasValidPressure != null);
        
        if (_autoManager.HasValidPressure == true)
            Console.WriteLine("  ✓ الضغط: مناسب");
        else
            Console.WriteLine("  ✗ الضغط: غير مناسب");
        
        // فحص المفصل
        _autoManager.PerformHingeCheck();
        await WaitForCondition(() => _autoManager.HasValidHinge != null);
        
        if (_autoManager.HasValidHinge == true)
            Console.WriteLine("  ✓ المفصل: سليم");
        else
            Console.WriteLine("  ✗ المفصل: معطوب");
    }
    
    private void SetupEventHandlers()
    {
        // حدث القراءة المستقرة
        _autoManager.ReadingStabled += (sender, reading, min, max, fall, rais) =>
        {
            Console.WriteLine($"  نقطة {_currentPointIndex + 1}: {reading} ({min}-{max})");
            
            // حفظ القراءة
            SaveReading(_testingPoints[_currentPointIndex], reading, min, max);
            
            // الانتقال للنقطة التالية
            _currentPointIndex++;
            
            if (_currentPointIndex < _testingPoints.Count)
            {
                // تحديد النقطة التالية
                _autoManager.SetPoint(_testingPoints[_currentPointIndex]);
                
                // بدء القراءة من النقطة الجديدة
                _autoManager.StartReading();
            }
        };
        
        // حدث توقف القراءة
        _autoManager.ReadingStopped += (sender) =>
        {
            Console.WriteLine("  توقفت القراءة");
        };
        
        // حدث الفصل
        _autoManager.Disconnected += (sender) =>
        {
            Console.WriteLine("⚠ تحذير: انقطع الاتصال!");
            // محاولة إعادة الاتصال
            _autoManager.RefreshCSAConnection();
        };
    }
    
    private async Task ProcessAllPoints()
    {
        if (_testingPoints.Count == 0)
        {
            Console.WriteLine("✗ لا توجد نقاط للاختبار");
            return;
        }
        
        // بدء من النقطة الأولى
        _autoManager.SetPoint(_testingPoints[0]);
        _autoManager.StartReading();
        
        // انتظار معالجة جميع النقاط
        await WaitForCondition(() => _currentPointIndex >= _testingPoints.Count);
        
        Console.WriteLine($"✓ تمت معالجة {_currentPointIndex} نقطة");
    }
    
    private async Task WaitForCondition(Func<bool> condition, int timeoutMs = 30000)
    {
        var startTime = DateTime.Now;
        
        while (!condition())
        {
            if ((DateTime.Now - startTime).TotalMilliseconds > timeoutMs)
            {
                throw new TimeoutException("انتهى وقت الانتظار");
            }
            
            await Task.Delay(100);
        }
    }
    
    private List<TestingPoint> LoadTestingPoints()
```

## 10. ملاحظات مهمة للمطورين

### 10.1 Best Practices

```csharp
// ✓ صحيح: استخدام Singleton
var csaManager = CsaEmdUnitManager.Instance;

// ✗ خطأ: إنشاء instance جديد
var csaManager = new CsaEmdUnitManager(); // لا تفعل هذا

// ✓ صحيح: إلغاء الاشتراك في الأحداث
csaManager.MeterValueChanged -= handler;

// ✗ خطأ: ترك الأحداث مشتركة
// يسبب memory leak

// ✓ صحيح: إغلاق الاتصال عند الانتهاء
csaManager.CloseConnection();

// ✗ خطأ: ترك الاتصال مفتوح
```

### 10.2 التعامل مع Threads

```csharp
// الأحداث تأتي من Thread منفصل
// استخدم Invoke للوصول لـ UI

csaManager.MeterValueChanged += (sender, reading, min, max) =>
{
    // إذا كنت في WinForms أو WPF
    if (labelReading.InvokeRequired)
    {
        labelReading.Invoke(new Action(() =>
        {
            labelReading.Text = reading.ToString();
        }));
    }
    else
    {
        labelReading.Text = reading.ToString();
    }
};
```

### 10.3 الأداء والتحسين

```csharp
// تقليل تكرار الأحداث
private DateTime _lastUpdate = DateTime.MinValue;

csaManager.MeterValueChanged += (sender, reading, min, max) =>
{
    // تحديث الواجهة كل 100ms فقط
```
